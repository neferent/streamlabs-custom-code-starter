How to use

No build step, no install. It's just copy and paste.

Download

Grab the ZIP and extract it anywhere on your machine.

Preview locally

Open the folder in Phoenix Code and use its built-in live preview to check layout and animations.

Open a widget in Streamlabs

In Streamlabs, open the widget you want to customise and find the Custom HTML / CSS / JS fields.

Paste

Copy the contents of each file into the matching field. For most widgets paste everything inside the <body> tag — the outer HTML wrapper is local-preview scaffolding only.

Good to know

A few things that will save you time.

🌐

Chrome only. Streamlabs Desktop and OBS embed a Chromium-based browser source. No need for cross-browser compatibility.

📦

jQuery is pre-loaded. Streamlabs injects jQuery 3.x automatically. The <script> tag in each HTML file is for local preview only.

⏱️

Alert duration. Set your alert duration about 1 second longer than your animation or video to avoid cut-offs. The DOM resets automatically after each alert.

🔤

Tokens. Placeholders like {name}, {amount}, and {message} are replaced by Streamlabs at runtime. They won't work in local preview.

📡

Events won't fire locally. Use the dispatch calls in Snippets/fake-events.js to simulate events in your browser console during development.

💡

Third-party libraries in alerts. Use the ensureDependencies pattern in Snippets/dependency-loader.js to load CDN libraries like Velocity.js or Anime.js before your alert code runs.
